# Car Price Prediction Model

A comprehensive machine learning project that predicts car prices based on various features using Linear Regression. This project follows a structured 14-step data science workflow.

## 🚀 Project Workflow

1.  **Understand the Problem Statement**: Predicting continuous car prices.
2.  **Data Collection**: Sourcing real-world automotive data.
3.  **Import Libraries**: Using Pandas, Scikit-Learn, and Seaborn.
4.  **Import Dataset**: Loading the `CarPrice_Assignment.csv`.
5.  **Data Integrity**: Checking for duplicates and null values.
6.  **Data Cleaning & EDA**: Visualizing distributions and correlations.
7.  **Manhotten Coding**: Implementing One-Hot Encoding for categorical features.
8.  **Data Splitting**: 80/20 Train-Test split.
9.  **Problem Classification**: Identifying the task as Regression.
10. **Model Training**: Fitting the Linear Regression algorithm.
11. **Evaluation**: Measuring MAE, MSE, and R2 Score.
12. **Accuracy**: Analyzing model performance metrics.
13. **Testing**: Validating predictions on unseen data.
14. **Deployment**: Saving the model for production use.

## 📊 Key Insights
- **Engine Size** and **Horsepower** are the strongest predictors of price.
- **One-Hot Encoding** was crucial for handling categorical data like fuel type and car body.
- The model achieves a high R2 score, indicating a strong fit for the dataset.
